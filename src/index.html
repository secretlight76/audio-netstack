Technical Documentation

Packetization Process

L'audio numérique est découpé en paquets pour être transporté sur un réseau IP. Chaque paquet contient un nombre fixe d'échantillons audio plus des en-têtes réseau (Ethernet, IP, UDP, RTP).

Latency Components

La latence provient du temps nécessaire pour remplir un paquet (paquetisation), des buffers de stabilisation, et du transit réseau. Plus le paquet est gros, plus la latence augmente.

Performance Trade-offs

Peu d'échantillons par paquet = faible latence mais beaucoup de paquets (charge réseau). Beaucoup d'échantillons = moins de paquets mais latence élevée.

Protocol Comparison

AES67 est un standard ouvert qui utilise RTP (12 octets d'en-tête supplémentaires). Dante est propriétaire, basé sur UDP directement, légèrement plus efficace.

Bandwidth Calculation

La bande passante = Taille totale du paquet × Nombre de paquets/seconde. Elle inclut tous les en-têtes réseau (overhead). Un flux 8 canaux @ 48kHz utilise typiquement 5-10 Mbps.

Jitter Buffer Function

Buffer de réception qui compense les variations de délai réseau (gigue). Trop faible = dropouts. Trop élevé = latence inutile. 2-5 ms suffisent sur un réseau optimisé.
